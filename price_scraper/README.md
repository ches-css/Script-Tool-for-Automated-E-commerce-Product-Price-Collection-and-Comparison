```

│  │  cli.py      │  │  web/        │  │  api.py      │       │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘       │
└─────────┼─────────────────┼─────────────────┼───────────────┘
          │                 │                 │
┌─────────┼─────────────────┼─────────────────┼───────────────┐
│         ▼                 ▼                 ▼               │
│              核心采集与处理引擎 (Core Engine)                  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │  采集器      │  │  数据清洗    │  │  分析推荐    │       │
```

## 核心模块说明

1. **scraper.py** - 数据获取核心逻辑
   - 支持多平台（京东、淘宝、拼多多）模拟采集
   - 关键词搜索采集
   - 商品信息抓取：名称、价格、销量、店铺评分、链接

2. **cleaner.py** - 数据清洗去重
   - 价格标准化（统一为数值）
   - 销量标准化（万/千/百转换）
   - 重复商品检测与去重
   - 缺失值处理

3. **analyzer.py** - 分析与推荐
   - 价格排序（低到高）
   - 性价比计算（综合价格、销量、评分）
   - 横向对比矩阵
   - 价格趋势分析

4. **visualizer.py** - 数据可视化
   - 价格分布柱状图
   - 平台对比雷达图
   - 价格趋势折线图
   - 性价比散点图

## 使用方法

### 命令行工具

```bash
# 安装依赖
pip install -r requirements.txt

# 按关键词采集
python cli.py search "iPhone 15" --platforms jd,tb,pdd --limit 20

# 查看采集结果
python cli.py report --sort price --chart

# 导出数据
python cli.py export --format csv --output result.csv
```

### Web 演示

```bash
python api.py
# 打开 http://localhost:5000
```
